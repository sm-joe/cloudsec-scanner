# CloudSec Scanner v0.1.0

Stable standalone CLI release for targeted infrastructure-as-code and supply-chain security checks.

- Native Terraform HCL/plan, selected CloudFormation, Kubernetes, Azure ARM, GCP and Dockerfile rules.
- Secret-pattern detection with redacted credential evidence.
- Resolved package inventory, OSV advisory enrichment, alias deduplication, pagination and CycloneDX SBOM.
- Optional Trivy container scans and read-only AWS inventory.
- JSON/SARIF/text reports, coverage withholding, severity-bound exceptions, resource-aware fingerprints and local history.

- Red FAILED findings and green PASSED resource assessments, actual rule IDs and full finding fingerprints.
- Coverage-aware pass counts, resource and remediation context, automatic terminal color detection and explicit color controls.
- Plain-text file exports and unchanged JSON/SARIF contracts, exit policy and scanner engine.
- Product README and dedicated rule, reporting and CI guides.

## Install

Download the wheel and checksum manifest from this release. In an isolated Python 3.11–3.13 environment:

```bash
sha256sum -c SHA256SUMS
python -m pip install --force-reinstall --no-cache-dir cloudsec_scanner-0.1.0-py3-none-any.whl
cloudsec --version
cloudsec scan infrastructure/ --scanner iac --no-history --color always
```

Download all files listed in the checksum manifest before checking it. GitHub CLI users can verify provenance using `gh attestation verify cloudsec_scanner-0.1.0-py3-none-any.whl --repo sm-joe/cloudsec-scanner`.

## Scope

Linux, Windows and macOS; selected native rules only. Not full CIS certification, not a substitute for comprehensive provider-specific review. Unsupported/unresolved inputs may withhold coverage. Optional integrations require Trivy or AWS credentials. No dashboard, server, database service, PyPI publication or container image is required or included.
